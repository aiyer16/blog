Quartz + Obsidian: my setup

Mar 14, 2025·6 min read·#meta#tools

I've tried a dozen ways to publish my notes, and this is the first one that stuck. The short version: I write everything in Obsidian, and Quartz turns the vault into this site. No copy-paste, no reformatting — I commit and it's live.

Why this combo

Obsidian is where the thinking happens — local files, fast linking, no lock-in. Quartz is the thinnest possible layer between those files and the web. Together they keep writing and publishing in one motion.

✦
Note
Everything stays as plain Markdown. If either tool disappears tomorrow, my writing is untouched.

The publishing flow

The whole loop is three steps, and the last one is automatic:

  • Write a note in Obsidian, link it to others with [[wikilinks]]
  • Mark it publish: true in frontmatter
  • Push to GitHub — the build deploys itself

Custom styling

Quartz exposes its theme through a config object and a single SCSS file. A few lines is enough to make it feel like yours:

# quartz.config.ts
colors: {
  lightMode: {
    light: "#f7f6f2",
    secondary: "#5f8f6a",
    darkgray: "#34332e",
  }
}
